# java-blackjack

블랙잭 미션 저장소

## 패

- 숫자의 합이 21을 넘으면 패배한다.

## 플레이어

- 참가자는 닉네임을 가진다.
- 시작 시 2개의 카드를 받는다.
- 카드를 더 받을지, 말지를 결정한다

## 덱

- 플레이어에게 카드를 배분한다.
- 콜, 스테이에 따라 카드를 배분한다.
- 닉네임 순서대로 카드를 배분한다.
- 한 번 사용된 카드는 사용되지 않는다.

## 딜러

- 16이하면 카드를 받고 17이상으면 카드를 받지 않는다.

## 카드

- 스페이드, 클로버, 하트, 다이아
- 조커는 제외한다.

### 에이스

- 1점 or 11점

### 일반 카드

- 1~10 숫자가 곧 점수
- J,Q,K : 10점

## 게임

- 딜러, 참가자 비교해 승패 결정한다.
    - 21에 가까울수록 딜러, 참가자 중 승패가 결정된다.
    - 같다면 무승부다
    - bust 하지 않은 쪽이 승리한다.
    - 둘 다 bust일 경우 딜러가 승리한다
- 딜러는 모든 참가자들과 비교해 승과 패를 계산한다.

## 입출력 요구사항

### 입력

#### 게임 참여자 입력

```angular2html
게임에 참여할 사람의 이름을 입력하세요.(쉼표 기준으로 분리)
pobi,jason
```

#### 콜,스테이 입력

```angular2html
pobi는 한장의 카드를 더 받겠습니까?(예는 y, 아니오는 n)
y
```

### 출력

#### 첫 카드 2장의 배분에 대한 결과 출력

```angular2html
딜러와 pobi, jason에게 2장을 나누었습니다.
딜러카드: 3다이아몬드
pobi카드: 2하트, 8스페이드
jason카드: 7클로버, K스페이드
```

#### 한장의 카드를 받았을 때 결과 출력

```angular2html
pobi카드: 2하트, 8스페이드, A클로버
```

#### 딜러가 카드를 받을 수 있는지 없는지 출력

```angular2html
딜러는 16이하라 한장의 카드를 더 받았습니다.
```

#### 최종 승패 결과 출력

```angular2html
## 최종 승패
딜러: 1승 1패
pobi: 승
jason: 패
```
